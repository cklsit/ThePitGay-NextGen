# 神话之锤：攻击与生命术语表（定稿）

> 状态：**定稿**，补齐 `MYTHIC_HAMMER_ENCHANTS_ANSWERS.md` Q6 承诺的术语表。
> 关联：`MYTHIC_HAMMER_ITEM.md`（锤本体）、`MYTHIC_HAMMER_STATUS.md`（状态与冲突规则）。
> 用途：统一 100 条附魔清单中「重击 / 命中 / 收锤 / 挥空 / 前摇 / 攻速 / 冲刺」等词的实现口径，避免各附魔自造计时。
> 本文分四部分：①核心术语 ②生命与资源术语 ③数值口径 ④校验与口径说明。

## 一、核心术语

| 术语 | 定义 | 判定口径 | 1.21 实现映射 | 禁止口径 |
| --- | --- | --- | --- | --- |
| 满蓄力 | 攻击冷却进度达到 1.0 | 冷却进度 `>= 1.0` | 攻击冷却进度读取（Bukkit `HumanEntity` 侧 API，落地时对照 Paper 1.21.8 javadoc 复核） | 不得用「按住右键时长」实现 |
| 重击 | 满蓄力状态下的一次近战命中 | 满蓄力 + `EntityDamageByEntityEvent` 且主手为锤 | 伤害事件 + 冷却进度 | 不得与「暴击」（跳跃下落）混用 |
| 命中 | 一次近战攻击判定到至少一个实体 | `EntityDamageByEntityEvent`，damager 为玩家、主手 `mythic_hammer` | 统一 `CombatListener` 伤害管线 | 不含对方块、对盔甲架、对自身 |
| 挥空 | 一次攻击发起但未命中任何实体 | 攻击动作与伤害事件配对差集，服务端自维护计数 | 自定义 `meleeMissCount`，仅主手锤时累加 | 不含「命中了但被护盾抵消」（仍算命中） |
| 收锤 | 自上次攻击到冷却重新满的间隔 | 冷却进度 0→1 的时长，按 `ATTACK_SPEED` 换算 | 冷却进度差；不额外起计时器 | 不得与「前摇」各起一套计时 |
| 攻击间隔 | 两次可造成伤害的攻击之间的最短时间 | `1 / 有效攻速` | `Attribute.ATTACK_SPEED` 的 `AttributeModifier` | 不得用 `BukkitRunnable` 自行限流 |
| 前摇 | 发起到伤害判定的间隔 | 1.21 无该属性；**统一并入攻击冷却**，视觉上用粒子 / 动画表达 | 与「攻击间隔」同一套数值 | 不得新增独立属性或第二套冷却 |
| 攻速 | 每秒可完成的满蓄力攻击次数 | 基础 **0.6**（原生重锤，冷却约 1.67 秒），所有附魔修正求和后 clamp 到 ±30% | `Attribute.ATTACK_SPEED` + `EquipmentSlotGroup.MAINHAND` | 不得逐条附魔各写一个 modifier |
| 冲刺 | 疾跑状态 | `Player#isSprinting()` | 原版疾跑 | 与 1.9+ 的「冲刺攻击 / 暴击」区分 |
| 站定 | 连续 N 秒内位移小于阈值 | 位置采样，阈值 0.1 格 / tick | `PlayerMoveEvent` 或位置快照 | 不得以「未按键」代替 |
| 落点 | 重击命中时在目标脚下的地面坐标 | 目标位置向下取整 | `Location` + 方块坐标 | 不得用玩家视线终点 |

**术语关系**：`收锤`（冷却期）→ `满蓄力` → 玩家发起 `重击`；`命中` 则结算附魔，`挥空` 则累加 `meleeMissCount`。`23 摇臂` / `51 缓锤` / `65 短砧` / `73 千锻` / `95 灼砧` 五条全部折算到同一个 `ATTACK_SPEED` 修正值，求和后统一 clamp（见 `MYTHIC_HAMMER_STATUS.md`）。

## 二、生命与资源术语

| 术语 | 定义 | 备注 |
| --- | --- | --- |
| 生命值 | 玩家血量，单位 ❤ | 回复、吸收、掉血均指此项；**不改变物品耐久** |
| `live` | 神话之锤当前生命（物品耐久） | 消耗到 0 物品不可用；写入 PDC `live` |
| `maxLive` | 生命上限 | 写入 PDC `maxLive`；锤定 **I 100 / II 120 / III 135**（常驻高生命，非 1% 稀有） |
| 阈值 60% / 30% | `live / maxLive` 的着色与部分附魔生效边界 | 沿用 `IMythicItem.java:178-179` |
| 消耗 N 点 `live` | 直接减 `live`，clamp 到 0 | 同一 tick 内所有条目合计最多 2 点（见 STATUS 文档） |
| 回复 N 点 `live` | 直接加 `live`，clamp 到 `maxLive` | 仅 43 / 49 / 64 / 80 / 92 / 97 / 100 等条目及修复机制可回 |
| 护盾值 | 独立于血量的可抵消层 | 复用 `AegisEnchant.java` 的护盾层语义，不占 `live` |
| 生命吸收 / 金心 | `absorptionAmount` | 与生命值、`live` 三者互不影响 |

> 严格区分：「回复生命值」只作用于玩家血量；「回复 `live`」才延长物品可用次数。上一轮 Q15（24 锭心）的语义混用即因违反此条。

## 三、数值口径

| 单位 | 口径 | 示例 |
| --- | --- | --- |
| 百分比 `+X%` | **加法**并入伤害 / 减伤修正池，最后统一 clamp | `+6% / +9% / +12%` 指 tier 1 / 2 / 3 三个档位，非叠加 |
| 物品阶 `tier 1 / 2 / 3` | 决定抽取池、`maxLive`、季节掉率；物品名显示 I / II / III 阶 | `IMythicItem.java:104-108`；`EnchantButton.java:310-312` |
| 附魔等级 `level 1 / 2 / 3` | 与物品阶独立；由 `getMaxEnchantLevel` 限制 | 词条 lore 以 `RomanUtil.convert(level)` 显示（≥2 才显示），见 `AbstractPitItem.java:59-61` |
| ❤ | 半颗心 = 1 点生命值 | `0.5 ❤` = 1 点 |
| 秒 | 服务端 tick 换算，20 tick = 1 秒 | `2 / 3 / 4 秒` |
| 格 | 方块边长，欧氏距离 | `2 格` = 半径 2 的球形范围 |
| 点 `live` | 整数 | 消耗与回复均 clamp |
| 硬币 | 走 `PitGainCoinsEvent` | 56 铁账终值 5 / 10 / 15（见 RULINGS R5） |
| 冷却 | 自触发时刻起算，冷却中不重复触发、不重复扣 `live` | 与 `live` 消耗绑定时以冷却为准 |

**物品阶适配列统一读法**：`a / b / c` = tier 1 / 2 / 3 各自数值；「仅 tier 3」= 该条目只在 tier 3 池出现；「全阶同效」= 三阶同值但可能附冷却差异。列中须列出所有随物品阶变化的主数值，效果概述不得出现列中未列出的随阶数值。

## 四、校验与口径说明

| 校验项 | 结果 |
| --- | --- |
| 100 条清单中的攻击术语是否全部落入本表 | 是（重击 / 命中 / 收锤 / 挥空 / 前摇 / 攻速 / 冲刺 / 站定 / 落点 / 满蓄力） |

| 生命值 / `live` / 护盾 / 生命吸收是否四者分立 | 是 |
| 是否含实现代码 | 否 |
