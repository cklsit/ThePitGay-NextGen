## 一、设计说明

### 1.1 项目背景

- 仓库 `docs/MIGRATION_PAPER_1.21.md` 记录 ThePitUltimate 向 1.21.x 的适配（目标 Paper 1.21.8、Java 21、物品数据由 NBT 迁至 PDC、`AttributeModifiers` 重写、枚举与粒子/全息/聊天层改造）；`README.md` 中的 1.8.8 为 master 基线，迁移在 `feat/paper-1.21.8` 分支推进。
- 近期提交已加入若干新功能：挂机池自动精通、时空商人、垃圾桶命令与配置化、实体硬币兑换、稀有附魔「我拒绝」等。本次在既有神话之剑 / 神话之弓 / 神话之甲体系上新增重锤品类「神话之锤」。
- 物品模型见 `IMythicItem`：以罗马数字标记 I / II / III 阶，附魔按 `tier` 分池（`custom.yml` 的 `rate` 1 / 2 / 3），物品带 `live / maxLive` 生命值并按 60% / 30% 阈值变色；生命归零即不可用，可由凋灵工艺一类机制修复。

### 1.2 参考依据

| 维度   | 仓库依据                                                                                                                                                                                                                                                                                                | 本设计沿用方式                                                                                                         |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |

### 1.3 约束

- 编号 1–100 连续且唯一；名称、效果、描述均为新写，不复制仓库现有附魔条目，也不含任何原版附魔（锋利、保护、耐久、力量、击退、火焰附加、抢夺、时运、效率、无限、修补、经验修补、穿透、忠诚、穿刺、引雷、荆棘等）。
- 类别标签仅 `普通`、`稀有!`、`**<font color="green">季节性!</font>**` 三种；后者以绿色加粗呈现，采用内联 HTML 以兼容常见 Markdown 预览。
- 每条含 7 个字段：编号、中文名称、类别标签、阶适配、效果概述、生命属性适配、平衡定位。阶适配给出 I / II / III 三档数值或明确限定阶。
- 生命属性适配统一按 `live / maxLive` 表述，并沿用 60% / 30% 阈值语义；「回复生命值」仅作用于玩家血量，不补 `live`；「回复 live」才延长物品可用次数。
- 开放表独立于清单，只列编号；开放 = 可从神话之井获得且玩家可正常使用，未开放 = 既不可从神话之井获得也不可使用。
